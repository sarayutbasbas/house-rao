# HouseRao brand

Reference palette: butter `#FFF1AC`, blush `#F9BCDD`, lilac `#D5A4CF`, mauve `#B689B0`.
Light backgrounds use warm ivory; dark backgrounds use deep plum. Pastels highlight
surfaces and selected filters. Dark mauve ink ensures readable light-mode links.
Core foreground/background, muted text, button, filter and warning pairs were checked
for at least 4.5:1 contrast. All theme colors live in `src/app/globals.css`.

## Active assets

The app logo is `public/house-rao-logo-plum.png`. The Apple Home Screen icon is
`public/icons/apple-touch-icon-plum.png`; the install manifest uses
`public/icons/icon-plum-192.png` and `public/icons/icon-plum-512.png`. The browser
favicon is `src/app/icon.png`.
